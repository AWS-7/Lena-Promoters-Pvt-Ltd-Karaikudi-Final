## 🏗️ Projects Management (திட்டங்கள் நிர்வாகம்)

### **1. Add New Project (புதிய திட்டம் சேர்க்க)**

#### **Step-by-Step:**

1. **Go to Projects Page**
   - Click "Projects" in the sidebar
   - You'll see all existing projects

2. **Click "Add Project" Button**
   - Blue button at the top right
   - Form will appear

3. **Fill Project Details:**

   **a. Title (தலைப்பு)**
   - Example: "Sri Lakshmi Nagar Layout"
   - Required field

   **b. Location (இடம்)**
   - Example: "Karaikudi, Tamil Nadu"
   - Required field

   **c. Price (விலை)**
   - Example: "8.5 Lakhs"
   - Required field

   **d. Area Size (பரப்பளவு)**
   - Example: "2400 sq.ft"
   - Optional field

   **e. Approval Status (அங்கீகார நிலை)**
   - Example: "DTCP Approved"
   - Optional field

   **f. Description (விளக்கம்)**
   - Write project details
   - Example: "DTCP approved layout with 40x60 plots"
   - Required field

4. **Upload Image (படம் பதிவேற்றம்)**

   **Important:** Wait for image upload to complete before saving!

   - Click "Upload Image" button
   - Select image from your computer
   - Wait for "Uploading image..." to complete
   - Preview will appear when done
   - **Only click Save after upload completes**

5. **Select Category (வகையைத் தேர்வு செய்ய)**

   Choose one of three categories:

   - **Government Approved (DTCP & RERA)**
     - For DTCP/RERA approved layouts
     - Blue color indicator

   - **Local Body Approved (Panchayat)**
     - For Panchayat approved layouts
     - Green color indicator

   - **Ready to Build (House Projects)**
     - For house construction projects
     - Amber color indicator

6. **Featured Toggle (முக்கியத்துவம்)**
   - Check "Featured on Homepage"
   - Project will show on homepage carousel
   - Only for important projects

7. **Click "Save"**
   - Button will be disabled during image upload
   - Wait for upload to complete
   - Then click "Save"
   - Project will be added to database

### **2. Edit Existing Project (திட்டத்தை திருத்து)**

1. **Find the Project**
   - Go to Projects page
   - Find the project in the table

2. **Click Edit Button**
   - Pencil icon button
   - Form will open with existing data

3. **Make Changes**
   - Update any field you want
   - Change image if needed
   - Update category

4. **Click "Save"**
   - Changes will be saved

### **3. Delete Project (திட்டத்தை நீக்கு)**

1. **Find the Project**
   - Go to Projects page
   - Find the project in the table

2. **Click Delete Button**
   - Trash icon button
   - Confirmation dialog will appear

3. **Confirm Delete**
   - Click "Delete" to confirm
   - Project will be permanently deleted

## 📱 Image Upload Tips (படம் பதிவேற்ற குறிப்புகள்)

### **Best Practices:**

1. **Image Format**
   - Use JPG, PNG, or WEBP
   - WEBP recommended (smaller size)

2. **Image Size**
   - Maximum: 5MB per image
   - Recommended: 1-2MB
   - Resize large images before upload

3. **Image Dimensions**
   - Recommended: 1200x800 pixels
   - Landscape orientation
   - Good quality but optimized

4. **Upload Process**
   - Wait for upload to complete
   - Don't close browser during upload
   - Check preview before saving

5. **Multiple Uploads**
   - You can upload unlimited images
   - No rate limit restrictions
   - Upload one at a time for best results

## 🐛 Troubleshooting (சிக்கல் தீர்ப்பு)

### **Image Upload Not Working:**

**Problem:** Image upload stuck or fails

**Solution:**
1. Check internet connection
2. Verify image size (max 5MB)
3. Try a different image
4. Refresh page and try again
5. Check if Cloudinary quota is full

### **Save Button Disabled:**

**Problem:** Cannot click Save button

**Solution:**
1. Check if image is uploading
2. Wait for "Uploading image..." to complete
3. Fill all required fields
4. Check for form errors

### **Project Not Showing on Website:**

**Problem:** Added project but not visible

**Solution:**
1. Check if project was saved successfully
2. Verify category selection
3. Check if featured is enabled (for homepage)
4. Clear browser cache
5. Wait 1-2 minutes for cache refresh

### **Analytics Not Updating:**

**Problem:** Visitor count not changing

**Solution:**
1. Check if tracking is enabled
2. Verify database connection
3. Check browser console for errors
4. Wait for next page load
